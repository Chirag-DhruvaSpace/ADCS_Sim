# Viewer texture sources

- Planet textures retained from the earlier procedural explorer (unused by the current Overview): `2k_mercury.jpg`, `2k_venus_atmosphere.jpg`, `2k_mars.jpg`, `2k_jupiter.jpg`, `2k_saturn.jpg`, `2k_uranus.jpg`, `2k_neptune.jpg`, `2k_saturn_ring_alpha.png`: unmodified Solar System Scope / INOVE maps, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), from [Solar System Scope textures](https://www.solarsystemscope.com/textures/).
- `galaxy-dust-v1.png`: generated using the built-in imagegen tool for this project, with an actual transparent background. Illustrative galaxy artwork, not an astronomical observation. Retained from the earlier procedural explorer; the current Overview uses the supplied video for distant views.

Galaxy asset generation prompt (built-in tool):

> Use case: stylized-concept, photorealistic astronomical VFX asset. Create a production-quality high-resolution RGBA texture of one Milky Way-like barred spiral galaxy, seen EXACTLY face-on from directly above, orthographic, centered, circular overall silhouette, filling about 85% of the square image. This will be mapped onto a plane inside an interactive 3D universe renderer, tilted by code; do NOT bake any perspective or edge-on tilt. Four organically irregular spiral arms, intricately branching charcoal interstellar dust lanes, countless tiny pinpoints of stars embedded in luminous diffuse stellar populations, warm ivory/amber central bulge and bar, muted pale blue-white outer arms with a few faint pink star-forming knots. Realistic long-exposure astronomical photography and cinematic feature-film VFX, intricate nonrepeating dust texture and granular detail at multiple scales, restrained physically convincing colors, luminous but no clipped white center, no cartoon, no schematic, no thick regular arm curves. Galaxy outskirts must fade naturally into actual transparency. Background completely transparent RGBA, no background stars, no border, no text, labels, symbols, UI, planets, lens flare, or black hole; the black hole will be animated separately in the 3D engine. A texture asset, not a finished scene.

The close Earth view shades its active day map under weak moonlight without synthetic city-light dots. The zoomed-out Overview uses a separate NASA night-light composite so cities remain legible at globe scale. This composite is static imagery, not lighting reconstructed for the simulation date.

- `8k_earth_daymap.jpg`, `8k_earth_clouds.jpg`, `2k_earth_clouds.jpg`: Solar System Scope / INOVE, https://www.solarsystemscope.com/textures/ , licensed under Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/). Original files, used without image edits. Cloud luminance is used as opacity at render time.
- `earth-day.jpg`, `earth-night.jpg`, `earth-water.png`: existing viewer assets from https://unpkg.com/three-globe/example/img/ (Blue Marble, night lights and water mask).
- `moon.jpg`: existing viewer asset from https://raw.githubusercontent.com/mrdoob/three.js/r160/examples/textures/planets/moon_1024.jpg .
- `2k_stars_milky_way.jpg`: Solar System Scope / INOVE, mirrored by [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Solarsystemscope_texture_2k_stars_milky_way.jpg), CC BY 4.0. Unmodified equirectangular map used for the decorative sky background. Its texture orientation is visual, not a star-catalog astrometric solution.
- `8k_stars_milky_way.jpg`: Solar System Scope / INOVE, mirrored by [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Solarsystemscope_texture_8k_stars_milky_way.jpg), CC BY 4.0.
- `4k_earth_daymap.jpg`, `4k_earth_clouds.jpg`: bicubic half-resolution versions of the corresponding 8K Solar System Scope maps for the automatic/balanced quality tier.
- `nasa_black_marble_2016_8192.jpg`, `nasa_black_marble_2016_4096.jpg`: bicubic reductions of the [NASA Earth at Night 2016 color composite](https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/) (original 13,500 × 6,750 pixels). NASA media is used under its [image/media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). The night-light texture is a static composite, not a reconstruction for the simulation date.
- `2k_stars_visible.jpg`, `8k_stars_visible.jpg`: gamma-adjusted versions of the Solar System Scope star maps (gamma 0.70) so the Milky Way remains visible behind the scene. These are decorative; Sun, Moon and spacecraft positions still come from simulation telemetry.
- `4k_stars_visible.jpg`: 4K bicubic reduction of the 8K star map with gamma 0.78, used by the balanced/automatic medium tier.

High, Ultra and 4K load 8K day/cloud/night/sky maps when the GPU supports them. Balanced and Auto on devices reporting at least 8 GB of memory load 4K maps. Low and Auto on smaller machines use compact textures. Switching tiers disposes replaced GPU textures; stale asynchronous loads are discarded. Imagery is a static snapshot, not historical weather for the simulation date.

- `reference-space.jpg`: full-resolution frame at 95 seconds from the user-provided `videoplayback.webm`; used to join the live Overview Earth with the same sky in the scroll footage. `frontend/assets/media/overview-reference.mp4` preserves the supplied 3840 × 1664, 30 fps imagery from 95–250 seconds and is encoded with a keyframe every 0.2 seconds for seeking.
